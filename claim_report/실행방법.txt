■ 심사청구 통계 프로그램 v4 (모듈형) 실행 방법

[준비]  이 폴더 전체를 원하는 곳에 풀어 두세요. (예: C:\Users\bhm99\Documents\claim_report)
        파이썬 3.9 이상이 설치되어 있어야 합니다.

[실행]  실행.bat 더블클릭
        - 처음 한 번은 패키지를 설치하느라 조금 걸립니다.
        - 처음에 "Email:" 이 뜨면 그냥 Enter.
        - 브라우저가 안 열리면 http://localhost:8501 로 접속.
        끄려면 검은 창을 닫으세요.

[사용]
  1) "샘플 데이터로 시작" 클릭 (또는 왼쪽에 엑셀/CSV 올리기)
  2) 위쪽 '조회 조건'에서 기간/환자구분/진료과를 바꾸면 모든 숫자·차트·보고서가 같이 바뀝니다
  3) 맨 위 '자동 요약' → 숫자 카드 → 차트 → 상세 통계표 → 보고서(Excel/PDF) 순서입니다
  4) '결과 검증' 탭: 병원이 손으로 만든 통계표를 올려 프로그램 결과와 비교

[연습용 파일 (모두 가상 데이터, prototype/data/ 폴더 안에 있습니다)]
  심사청구_더미데이터_2026상반기.xlsx   기본 샘플
  연습용_컬럼명다른파일.xlsx            제목 줄 있음 + 컬럼 이름 다름 + 숫자가 '1,234' 글자 → 자동 인식 연습
  검증_연습용_병원결과표.xlsx           '결과 검증' 탭 연습 (일부러 틀린 값이 들어 있음, 통계는 '진료과별' 선택)
  ※ 실제로 쓸 때는 prototype/ 폴더를 지우거나 config.py 의 PROTOTYPE_MODE = False 로 바꾸세요. (수정가이드.txt 참고)

[참고]  화면 색과 '사용 통계 전송 끄기'는 .streamlit/config.toml 이 담당하므로, 실행.bat 없이 'streamlit run app.py' 로 켜도 같습니다.
        (이 폴더에서 실행해야 적용됩니다)
[구조 요약]  병원 엑셀을 구조요약.bat 위로 끌어다 놓으면 값 없이 구조만 요약해 줍니다 (AI 에게 구조만 공유할 때 사용)
[고칠 때]  수정가이드.txt 와 AGENTS.md 를 보세요. 고친 뒤에는 점검.bat 을 더블클릭해서 [OK] 인지 확인하세요.
[이전 버전]  기존 app.py / app_v3.py 는 이 폴더와 상관없이 그대로 있습니다.
