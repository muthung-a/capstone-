[실제 사용으로 전환하기]  (병원 통계가 정해진 뒤)

  2) stats_config.py 에 병원 통계를 정의  (파일 안의 '새 통계 추가 예시' 참고)

[통계표 모드 — '항목이 세로, 기간(월)이 가로'인 표를 읽을 때]
  병원이 매달 만드는 통계표(예: 병상가동률, 총재원환자수, 인건비 … 항목이 세로, 월이 가로)를 올리면 항목을 자동으로 찾아
  항목별 추이 차트 / 전기 대비 증감 / 자동 요약 / 보고서(Excel·PDF)를 만들어 줍니다. 항목이 늘어도 코드를 고치지 않아도 됩니다.
  · 파일을 올리면 왼쪽 '데이터 모양'을 자동으로 추천합니다. 틀리면 직접 바꾸세요. (청구 내역 ↔ 통계표)
  · 자동으로 처리: 병합 셀 채우기, '본 인 부 담 금' → '본인부담금', '1,234' / '87.5%' / '(123)' / '△123' 숫자, '합계·평균' 열 제외
  · 여러 줄 · 합쳐진 머리글도 읽습니다: 예) '2026년'(여러 칸에 합쳐짐) / '입원·외래'(합쳐짐) / '1월 2월 …'
      줄마다 '연도 / 월 / 구분'을 내용으로 판단해서 '2026-01'(기간)과 '입원'(구분)으로 나눕니다. 표 제목 줄은 머리글로 보지 않습니다.
  · 자동으로 못 맞추면 왼쪽 '표 읽기 설정'에서 고치세요:
      - 항목 이름이 있는 열 / 값(기간) 열 (엑셀의 A, B, C … 문자)
      - 머리글 첫 줄 / 마지막 줄 번호 (여러 줄 머리글이면 두 번호가 다름)
      - '머리글을 이렇게 읽었어요': 열마다 기간·구분이 맞게 나뉘었는지 확인 (틀리면 머리글 줄 번호를 바꿔 보세요)
      - 표가 가로세로 반대이면 '표를 가로↔세로 바꿔서 읽기'
      - 같은 항목이 블록마다 반복되는 표(예: 병동별로 '입원 환자수'가 여러 번): 블록 이름을 읽는 방식 2가지가 있어요.
          · 값 없는 제목 줄('[일반병동]' 등)이 블록 위에 있으면 → '값 없는 제목 줄을 블록 이름(구분)으로 사용'
          · 항목 왼쪽 열에 블록 이름이 합쳐져 있으면 → '항목 열 순서 바꾸기'
        (같은 항목이 겹치면 자동으로 알맞은 쪽을 골라 둡니다. 그래도 '#2' 같은 이름이 보이면 직접 켜 보세요)
          · 엑셀의 '합쳐진 칸'은 추측하지 않고 진짜 병합 범위(.xlsx 안의 정보)를 읽어서 범위 전체에 채웁니다. (빈 줄이 합쳐진 칸 안에 끼어 있어도 안전)
          · 합쳐지지는 않았지만 '위와 같음'으로 비워 둔 칸(항목은 첫 줄에만 적고 아래는 비움)은 두 가지 설정으로 처리합니다:
              '세부 구분 열도 합쳐진 칸 채우기', '빈 줄을 건너서도 \'위와 같음\' 채우기 이어가기' (겹침/항목 없는 줄이 생기면 자동으로 켜 봅니다)
          · 자동 해석은 '겹침이 0이 되고 값을 하나도 잃지 않을 때만' 채택합니다. 조금 나아지는 정도로는 바꾸지 않으며, 바꿨다면 왼쪽에 파란 안내가 나옵니다.
          · '항목 이름이 없는 줄 N개 제외' 경고에는 엑셀 줄 번호 예와 '그 줄들에서 글자가 있는 열'이 나옵니다. 그 열이 항목 이름 열이면 추가하세요.
          · 블록 이름이 '항목 이름 열' 밖(예: 4번째 글자 열 D, E)에 있으면 → 겹침을 없애는 열을 자동으로 찾아 '블록(구분) 이름 열'로 추가합니다.
            이때 '그중 블록(구분) 이름 열'로 지정된 열이 선(구분)이 되고, 나머지 항목 이름 열은 합쳐서 항목 이름(차트 제목)이 됩니다.
          · 그래도 겹치면 노란 경고에 '엑셀 줄 번호 예: 9, 10, 11 …'이 나옵니다. 엑셀에서 그 줄들 근처를 보고 블록을 구분하는 이름이
            어디(어느 열/줄)에 적혀 있는지 찾아 '표 읽기 설정'에서 지정하세요. (찾기 어려우면 '구조 복제본'을 만들어 허락받고 전달)
      - 이름에 '율'이 있고 값이 0~1이면 %로 표시 (병상가동율 0.96 → 96%)
      - 항목과 구분(블록)이 반대로 읽히면 '항목 열 순서 바꾸기'. 자동 판단 기준: 세부 이름이 여러 블록에 반복되고,
        '합계' 행이 들어 있는 열을 구분(블록)으로 봅니다. 단서가 없는 애매한 표는 자동으로 뒤집지 않으니 직접 고르세요.
      - '합계 선도 차트에 그리기': 합계가 다른 선보다 3배 넘게 크면 기본은 꺼 둡니다 (합계는 숫자 카드에 그대로 나옴).
      - 값이 전부 0인 줄이 있으면 노란 경고가 나옵니다 (엑셀에서도 0인지, 수식 결과가 비어 있지 않은지 확인).
      - '원본 표 앞부분 보기'로 표 모양을 직접 확인
  · 병원 파일로 시험하는 순서
      1) 구조요약.bat 에 파일을 끌어다 놓기 → '통계표(항목 × 기간) 모양' 설명이 나오면 항목·기간 이름은 적히지 않습니다
      2) 프로그램에 올려서 항목 수/기간 수가 맞는지 보기 (위쪽 칩과 '읽은 결과: 항목 N개 · 기간 M개')
      3) 이상하면 위 설정을 바꿔 보고, 그래도 안 되면 '어떻게 이상한지'를 말로만 알려주세요 (예: "항목은 29개인데 14개로 읽힘")
  · 관련 파일: core/table_mode.py(읽기) core/table_stats.py(계산) ui/table_panel.py(왼쪽 설정) ui/table_dashboard.py(화면)
              reports/table_report.py(보고서 양식)   · 설정값: config.py 의 TABLE_DEFAULT_ITEMS, TABLE_MAX_CHARTS

     (공유가 어려우면 이름을 직접 컬럼1, 컬럼2 로 바꿔서 보여주거나, 화면의 '컬럼 연결'로 직접 연결하세요)
  ※ 컬럼 이름 줄을 못 찾은 시트는 이름도 숨깁니다. 주민번호/전화번호/긴 숫자 모양의 이름도 자동으로 숨깁니다.
  ※ 이 도구는 점검.bat 이 '값이 출력되지 않는지' 매번 확인합니다.

[구조 복제본 — 병원 파일을 AI 에게 못 보여줄 때, 구조 문제를 설명하는 가장 쉬운 방법]
  왼쪽 '공유용 구조 복제본 만들기' → '복제본 만들기' → '복제본 내려받기'
  · 이름과 값은 전부 가짜(항목_001, 무작위 숫자)로 바뀌고 구조(병합 셀·머리글 줄 수·같은 항목이 반복되는 모양·빈 칸·띄어쓰기·서식·0 인 칸)만 남습니다.
  · 시트 이름, 문서 속성(만든 이·회사), 메모, 이름 정의, 머리글/바닥글은 새 파일에 아예 옮기지 않습니다.
  · 원본 이름이 복제본에 남으면 파일을 만들지 않습니다. 보고에 '읽기 결과: 원본과 동일 ✓' 이 나오면 복제본이 원본과 같은 방식으로 읽힌다는 뜻입니다.
  · 남지 않는 것: 값 사이의 관계(합계 = 구분의 합 등)와 추세. 그래서 '구조가 이상하게 읽힌다'를 고치는 데는 충분하지만,
    '숫자가 맞는지' 확인은 원본으로 이 PC 에서 '결과 검증' 탭에서 하세요.
  · 복제본도 병원 파일에서 만든 것입니다. 직접 열어 확인하고, 병원/교수님의 허락을 받은 뒤에 보여주세요.
  · 작업 순서: 복제본 만들기 → 열어서 확인 → 허락 받기 → (허락되면) AI 에게 전달 → 코드 수정 → 원본으로 이 PC 에서 확인 → 결과를 말로 보고
