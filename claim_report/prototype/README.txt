이 폴더는 '프로토타입 전용' 기능만 모아 둔 곳입니다.

  data/            가상 데이터 엑셀 3개 (샘플 시작 / 컬럼 연결 연습 / 결과 검증 연습)
  __init__.py      '프로토타입' 배지·하단 안내 문구, 샘플 파일 위치
  screens.py       '샘플 데이터로 시작' / '샘플 데이터 끄기' 버튼
  sample_stats.py  가상 데이터를 보고 '가정해서' 만든 통계 4개  (병원 실제 통계로 교체 대상)
  checks.py        샘플 숫자에 의존하는 점검 항목

실제로 쓸 때는 이 폴더를 통째로 지우거나, config.py 의 PROTOTYPE_MODE = False 로 바꾸세요.
본 프로그램은 hooks.py 로만 이 폴더를 부르므로, 지워도 정상 동작합니다.
