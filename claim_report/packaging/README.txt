■ exe 로 만들어 병원 PC 에 배포하기

[구조]  exe 는 '실행 엔진'(파이썬 + 라이브러리)만 담고, 우리 프로그램 소스는 exe 옆의 app/ 폴더에 그대로 둡니다.
        → config.py / stats_config.py 를 메모장으로 고치고 프로그램을 껐다 켜면 바로 반영됩니다. (exe 를 다시 만들 필요 없음)
        → 새 통계를 정의하거나 화면 문구를 바꿔도 exe 재빌드가 필요 없습니다.

   ClaimReport 폴더/
     ClaimReport.exe     실행 엔진 (더블클릭하면 브라우저가 열림)
     _internal/          엔진이 쓰는 파일들 (건드리지 마세요)
     app/                우리 프로그램 (config.py, stats_config.py ... 여기를 고칩니다)
     점검.bat            설정을 고친 뒤 [OK] 확인   /   구조요약.bat  병원 엑셀의 '구조'만 요약(값 없음)
     사용방법.txt

[만드는 방법 A — 내 윈도우 PC 에서]   ※ 빌드할 때 한 번만 인터넷이 필요합니다
  1) 이 프로젝트 폴더가 있는 윈도우 PC 에 Python 3.9 이상이 설치되어 있어야 합니다.
  2) packaging\build_exe.bat 더블클릭 (몇 분 걸립니다)
  3) 끝나면 dist\ClaimReport 폴더가 생깁니다. 이 폴더 '전체'를 병원 PC 로 옮기세요. (약 500MB, USB 로 옮기면 됩니다)
  4) 병원 PC 에서 ClaimReport.exe 더블클릭. 파이썬 설치도 인터넷도 필요 없습니다.

[만드는 방법 B — GitHub 에서 대신 빌드]  (윈도우 PC 에서 빌드하기 어려울 때)
  1) 코드를 GitHub 에 올립니다. ★ 저장소는 반드시 Private 으로, 병원 데이터는 절대 올리지 마세요.
  2) 저장소의 Actions 탭 → build-exe → Run workflow
  3) 끝나면 Artifacts 의 ClaimReport-windows 를 내려받아 압축을 풉니다.

[이 폴더가 하는 일을 점검.bat 이 지켜줍니다]
  · launcher.py 의 import 목록에 app 이 쓰는 라이브러리가 모두 있는지 (빠지면 exe 에서 'No module named' 오류)
  · 서버가 이 PC 안에서만 열리는지 (127.0.0.1)  · .bat 파일이 윈도우에서 안전한지

[확인한 것 / 확인하지 못한 것]
  확인함  : 같은 PyInstaller 옵션으로 '리눅스용' 실행 파일을 만들어 시험했습니다.
           점검 전체 통과, 샘플 화면·숫자, Excel/PDF 다운로드(한글 폰트 포함), 컬럼 이름이 다른 파일 읽기, 구조 요약 모드,
           한글·공백이 든 폴더 경로, app/config.py 수정이 exe 재빌드 없이 반영됨, 이 PC 안에서만 접속, 바깥으로 나가는 요청 없음.
  못 함   : 윈도우 exe 를 직접 만들어 보지는 못했습니다. 아래는 윈도우에서 처음 돌릴 때 확인이 필요한 부분입니다.
           · build_exe.bat 이 끝까지 성공하는지 (실패하면 검은 창의 마지막 메시지를 알려주세요)
           · 윈도우 Defender / SmartScreen / 백신이 서명 없는 exe 를 막는지 → 병원 IT 담당자와 상의가 필요할 수 있습니다
           · 처음 실행 시 시작이 느릴 수 있습니다 (10~30초)

[알아두기]
  · 화면은 exe 안의 별도 창이 아니라 '기본 브라우저'(Edge/Chrome)에서 열립니다. 이 PC 안에서만 접속됩니다.
  · exe 에 서명(코드 서명)이 없으면 병원 보안 정책에 따라 실행이 막힐 수 있습니다.
  · 설치 마법사(setup.exe) 형태가 필요하면 이 폴더를 Inno Setup 같은 도구로 한 번 더 감싸면 됩니다. (지금은 폴더 복사 방식)
